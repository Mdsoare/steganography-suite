# Política de Segurança

## Versões Suportadas

Apenas a versão mais recente da branch `main` recebe atualizações de segurança.

| Versão | Suportada          |
| ------ | ------------------ |
| main   | :white_check_mark: |

## Reportando uma Vulnerabilidade

Caso identifique uma vulnerabilidade de segurança neste projeto, utilize o recurso de **Private Vulnerability Reporting** disponível na aba [Security](../../security/advisories/new) deste repositório.

Pedimos que não abra *Issues* públicas para relatar falhas de segurança antes que elas sejam corrigidas.
